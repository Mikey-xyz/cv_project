# Miguel Pereira — Cybersecurity CLI CV

> A CV written entirely in Bash.

This project is both a professional CV and a demonstration
of my Bash/Linux skills.

## Usage

./cv.sh

# CV related options
./cv.sh --about
./cv.sh --certifications
./cv.sh --contact
./cv.sh --education
./cv.sh --experience
./cv.sh --projects
./cv.sh --skills

# System basic analysis tools options
./cv.sh --security
./cv.sh --system
