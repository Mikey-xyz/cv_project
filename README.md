# Miguel Pereira - Cybersecurity CLI CV

> A CV written entirely in Bash.

This project is both a professional CV and a demonstration
of my Bash/Linux skills.

## Usage

```bash
./cv.sh
```

### CV options
```bash
./cv.sh --about 

./cv.sh --certifications

./cv.sh --contact

./cv.sh --education

./cv.sh --experience

./cv.sh --projects

./cv.sh --skills
```

### System & Security Options
```bash
./cv.sh --detect-environment

./cv.sh --detect-tools

./cv.sh --security-scan
```
